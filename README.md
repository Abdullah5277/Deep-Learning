# Deep-Learning

1. ANN.ipynb
    A Jupyter notebook focused on Artificial Neural Networks. It can be used to explore the fundamentals of neural networks, model building, training, and evaluation.  
    
2.ANN_mnist.ipynb
    A Jupyter notebook dedicated to applying an Artificial Neural Network to the MNIST dataset, which contains handwritten digit images from 0 to 9.
    

The notebook can be used to explore:

    Loading and preprocessing the MNIST dataset

    Building an ANN model

    Training the model on handwritten digit images

    Evaluating model performance

    Predicting handwritten digits
