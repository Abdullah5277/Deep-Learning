# Deep-Learning

1. ANN.ipynb
    A Jupyter notebook focused on Artificial Neural Networks. It can be used to explore the fundamentals of neural networks, model building, training, and evaluation.  
    
2.ANN_mnist.ipynb
    A Jupyter notebook dedicated to applying an Artificial Neural Network to the MNIST dataset, which contains handwritten digit images from 0 to 9.
    

The notebook can be used to explore:

    Loading and preprocessing the MNIST dataset

    Building an ANN model

    Training the model on handwritten digit images

    Evaluating model performance

    Predicting handwritten digits

3. Convolutional Neural Network (CNN) File: CNN.ipynb
This project focuses on implementing a Convolutional Neural Network (CNN) using deep learning techniques.
Topics covered:
- Loading and exploring image data
- Data preprocessing
- Feature extraction
- Convolutional layers
- Pooling layers
- Model training
- Image classification
- Accuracy evaluation
The goal is to demonstrate how CNNs can be used to extract features from images and perform image classification tasks.
Note: This project is for educational purposes.

    Deep Learning File: Deep_Learning.ipynb
This project focuses on understanding and implementing deep learning concepts using Python.
Topics covered:
- Introduction to deep learning

The goal is to demonstrate the fundamentals of deep learning and how neural networks can be used to solve machine learning problems.
